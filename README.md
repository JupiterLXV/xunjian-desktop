# 巡检缺陷图像标注软件

Windows 桌面版，当前版本 **50.4.0**。将原桌面 50.3.0 的目录同步、成果分组、成果回收站与操作记录，和联网版的账号登录、24 小时会话、系统托盘及发布保护整合在一起。

## 下载与使用

- [下载 Windows 安装程序和源码包](https://github.com/JupiterLXV/xunjian-desktop/releases/latest)
- [详细操作手册](操作手册.md)
- [开发与发布说明](docs/开发与发布.md)
- [版本更新说明](CHANGELOG.md)
- [验证记录](docs/验证记录.md)

安装包适用于 Windows 10 / 11 x64，自带运行组件。下载 `xunjian-desktop-50.4.0-windows-x64-setup.exe` 后运行中文安装向导。首次启动点击 **导入服务配置**，选择管理员私下提供的 JSON 文件，然后使用后端账号密码登录。

公开源码与公开安装包均不包含实际服务的 AES 密钥、账号、token 或用户照片。仓库中的 `api-config.example.json` 是空配置示例；实际服务配置需要单独获取。导入后使用 Windows 安全存储加密保存。

登录自成功起固定有效 24 小时，期间可以离线标注、保存、查看和恢复成果。普通保存和危急保存均写入本地，当前不调用后端保存记录接口，也不上传照片。

## 功能

- 原生目录访问、中文路径、图片预加载、圈框及缺陷标签。
- 缺陷原图、缺陷圈示图、危急缺陷三类成果输出。
- 二次编辑独立生成成果组，按组管理、删除和恢复。
- 文件变化自动同步，F5 手动刷新并保留当前编辑草稿。
- 成果回收站与最近 500 条操作记录。
- 本地草稿、目录记忆、保存任务重试与正常退出前的保存检查。
- 联网账号登录、机器码绑定和系统加密会话存储。
- 托盘、全屏、主题、界面缩放、可配置快捷键。

覆盖安装沿用 `%APPDATA%\巡检缺陷工具`，不会要求旧离线授权文件。本版卸载保留本地记录和草稿；成果回收站位于用户选择的输出目录中。

## 开发

使用 Node.js 22 或更新版本、npm 和 Windows x64：

```powershell
npm ci
npm test
npm start
```

开发运行同样可通过界面导入服务配置；也可将 `api-config.example.cjs` 复制为 `api-config.local.cjs`，填写开发环境配置。该文件被 Git 忽略，且不会进入公开安装包。

```powershell
npm run test:smoke
npm run dist
```

界面测试使用隔离用户目录、合成图片及本机模拟的加密服务，不使用真实账号。`npm run dist` 先生成混淆副本、执行行为回归，再构建 NSIS 安装程序并检查最终 EXE/ASAR 完整性。

安装包没有商业代码签名。请从本仓库 Release 下载并对照 SHA-256 校验文件；发布保护不是代码签名，也不保证无法逆向。
