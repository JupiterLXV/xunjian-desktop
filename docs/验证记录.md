## Electron 桌面流程

`npm run test:smoke` 在真实 Electron 中完成 8 个场景。另一次将 `XUNJIAN_SMOKE_APP_DIR` 指向 `.build/protected/app`，用混淆后的应用代码完成相同的 8 个场景。两次均未记录页面错误。

1. 未登录显示登录页，主进程拒绝目录选择和成果修改。
2. 导入服务配置，经实际 IPC、随机 IV 和 AES 协议登录；页面不持有 token。
3. 选择中文目录，通过应用文件协议读取合成图片。
4. 停止模拟后端后，仍可圈图、加标签和保存本地成果。
5. 二次编辑生成第二组成果，保留第一组。
6. 按组删除进入成果回收站，恢复后两组均存在；记录中有删除与恢复事件。
7. 外部增加照片后刷新显示，输入原图摘要保持不变。
8. 离线重启恢复加密会话和输入、输出目录记忆，没有再次请求登录。

测试使用独立用户目录、本机模拟后端、随机密钥、合成账号和合成图片。原生选文件对话框使用测试替身；实际主进程、页面、文件服务、系统安全存储和磁盘输出均参与。界面截图可在 [登录页](images/login.png) 和 [工作台](images/workspace.png) 查看。
